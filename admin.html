Conectar el panel

Para guardar cambios, el panel necesita una llave de acceso a tu repositorio de la web. Se pide una sola vez y se guarda solo en este navegador (no se sube a ninguna parte).

  1. Entra en GitHub → Fine-grained tokens (estando con tu cuenta Procreartes).
  2. En Repository access elige Only select repositories → aarongomez-web.
  3. En Permissions → Repository permissions, busca Contents y ponlo en Read and write.
  4. Pulsa Generate token, copia el código (empieza por github_pat_) y pégalo aquí abajo.

Consejo: ponle caducidad larga al token para no tener que repetir esto a menudo.
